01 — Featured app

Juniper

Local-first AI software for people who want a thoughtful assistant, visible model controls, and a clear boundary around private data.

Flagship · published prerelease 0.3.0-rc.7

Yours to configure.

Juniper gives you a chat workspace, assistant profiles, device-aware model recommendations, verified resumable model downloads, provider choices, explicit tool permissions, local persistence, and visible data-route boundaries.

The current repository tracks the unreleased 0.3.0-rc.17 development candidate. The public download remains the verified 0.3.0-rc.7 prerelease until a newer release is published.

Published platforms
Windows x64, Linux x86_64, Android 7.0+
Desktop runtime
Juniper-owned loopback llama.cpp process
Android note
Model management is available; packaged native local inference is not included in this prerelease
