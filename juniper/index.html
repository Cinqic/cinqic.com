Juniper is a local-first AI app for people who want a thoughtful assistant, visible model controls, and a clear boundary around private data.

Desktop release candidate in development

01 — Local first

Choose a model without becoming a systems administrator.

Juniper's Models Market detects the device profile, explains which compact models fit, and manages verified downloads and storage. The ordinary desktop path owns its local runtime instead of requiring Ollama or an account.

The current catalog focuses on instruction-tuned GGUF models below 1B parameters. Advanced users can still connect compatible external providers.

02 — A clear boundary

Private by default.

The app should tell you where your prompt goes.

Juniper labels on-device, local-network, remote, and unknown routes. It keeps credentials in the desktop operating-system store, makes tool permissions explicit, and does not add telemetry, analytics, or an account system.

03 — Status

Built in the open.

Juniper is a prerelease product. The repository contains the implementation, tests, architecture decisions, release workflow, and current limitations. Android shares the app shell and model-management direction; this candidate does not claim a packaged native local inference process on Android yet.
