Juniper

Your AI, your models, your machine. A thoughtful, local-first workspace for compatible providers and runtimes.

Version 0.2.0-rc.1 · release candidate

View downloads ↗Source on GitHub ↗

01 — The product

A clear boundary around your private data.

Juniper gives you visible provider and model controls, assistants, streaming chat, private conversations, attachments, export, and native SQLite persistence. It does not require a particular model family.

Connect a compatible Ollama, llama.cpp, or OpenAI-compatible endpoint. Provider credentials on desktop are stored by reference in the operating system keychain.

03 — Honest limitations

Useful, inspectable, still evolving.

Juniper does not claim native on-device GGUF inference, managed llama.cpp process ownership, MCP client calls, or completed real-model qualification. Mobile secure credential storage and file access have platform-specific limitations.

Juniper is separate from Juniper Auto, Cinqic’s open sparse Mixture-of-Experts research project.
