Cinqic app / notes

Your knowledge, in files you can keep.

Cinqic Notes is a local-first notes app for Markdown, plain text, projects, checklists, linked notes, and user-owned knowledge.

01 — Local first

A notes app that starts with ownership.

The project is built around user-owned knowledge and ordinary note formats rather than a hosted product. That makes the core idea straightforward: your notes should remain understandable and portable.

This page describes the current canonical project direction. It does not claim cloud sync, collaboration, AI features, or a particular platform.

02 — Current direction

A lightweight home for thinking.

The repository’s current description establishes these core workflows:

01

Markdown

Write in a format that remains readable and useful outside the app.

02

Plain text

Keep simple notes simple, without requiring a proprietary document format.

03

Projects

Organize notes around the work and ideas they belong to.

04

Checklists

Turn notes into lightweight, practical lists when a task needs a next step.

05

Linked notes

Connect ideas so a personal knowledge base can grow over time.

06

User-owned knowledge

Keep the center of gravity with the person creating and maintaining the knowledge.

03 — Status

Early, public, and not downloadable yet.

Cinqic Notes has no published GitHub release at this time, so there is no download button or version claim here. When a release and supported platforms are established in the canonical repository, this page can grow with them.

Current boundary: Cinqic Notes is useful without AI, and this site makes no claim that Juniper integration is implemented.
