# Cinqic website instructions

Keep this site static, fast, accessible, and honest. The public focus is Cinqic and Juniper Auto, an open, consumer-scale sparse Mixture-of-Experts research project in development. Use the centralized company data in `assets/js/company.js`; never claim a release, performance result, availability, privacy guarantee, certification, partner, social account, or download without evidence.

Future Juniper Auto capabilities (autonomy, tool use, memory, multi-domain competence, trained checkpoints) must not be presented as implemented until the canonical `Cinqic/Juniper-Auto` repository provides evidence. Describe them as research targets, not current behavior.

Use semantic HTML, keyboard-accessible interactions, visible focus states, and reduced-motion support. Do not add trackers, ads, external fonts, cookies, secret material, fake contact details, or dependency-heavy frameworks. Preserve `CNAME` and GitHub Pages deployment files. Run `python scripts/verify_site.py` after changes.
