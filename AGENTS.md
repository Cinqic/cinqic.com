# Cinqic website instructions

Keep this site static, fast, accessible, and honest. The public focus is Cinqic and Juniper, a future lightweight local-first assistant in development. Use the centralized company data in `assets/js/company.js`; never claim a release, performance result, availability, privacy guarantee, certification, partner, social account, or download without evidence.

Use semantic HTML, keyboard-accessible interactions, visible focus states, and reduced-motion support. Do not add trackers, ads, external fonts, cookies, secret material, fake contact details, or dependency-heavy frameworks. Preserve `CNAME` and GitHub Pages deployment files. Run `python scripts/verify_site.py` after changes.
