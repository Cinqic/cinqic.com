Product focus

Built to be useful, not oversized.

Juniper Baby 1 focuses on efficient assistance. It is being designed to use tools when deterministic tools are more reliable, prioritize local execution when practical, acknowledge uncertainty, and document limitations instead of hiding them.

Local-first

Designed to run near the user whenever practical instead of assuming every request belongs in the cloud.

Lightweight

Built around an efficient 0.8B-class model intended for modest systems and future mobile-focused development.

Tool-aware

Designed to use calculators, retrieval, files, and current information when language generation alone is not enough.

Honest by design

Guided by principles that prioritize truth, clarity, privacy, and user control.
