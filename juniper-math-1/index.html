01 — Current status

Designed, implemented, and validated at the architecture layer.

The official Juniper Math 1 repository reports that Phase 0 Foundation and Recovery and Phase 1 Architecture are complete. The frozen decoder-only Transformer has exactly 5,004,032 trainable parameters, verified programmatically. No model is trained yet, and no tokenizer, real dataset, or Cinqic Calculator integration exists yet.

The launch date above is the existing Cinqic project date carried forward during this migration; it is not evidence that a release is ready.

02 — Research question

How far can a highly specialized ~5M-parameter model go?

How capable, reliable, efficient, and truthfully calibrated can a purpose-built mathematical language model become at understanding natural-language math problems, decomposing them into verifiable operations, selecting deterministic mathematical tools, detecting ambiguity and unsupported requests, verifying results, and producing accurate answers?

03 — Tool-first reasoning

The model should not guess what a tool can verify.

Juniper Math 1 is intended to understand a request, reason about its structure, route approved deterministic operations when appropriate, interpret the result, verify it, and communicate the answer. Cinqic Calculator is the intended deterministic execution backend.

  1. UnderstandInterpret the mathematical request and its constraints.
  2. ReasonDecompose the problem into useful operations.
  3. RouteGenerate a structured request for a tool when appropriate.
  4. VerifyCheck the result before answering, or state uncertainty.

The planned initial tool surface includes calculator.evaluate, calculator.convert, and calculator.finance. These integrations are not production-ready or implemented yet.

06 — Scope and limits

Narrow scope is part of the design.

Initial intended areas include arithmetic, percentages, ratios, proportions, scientific calculations, scientific notation, basic algebra, word problems, unit conversions, financial mathematics, estimation, interpretation, tool selection, verification, ambiguity detection, and unsupported-request handling.

Advanced symbolic algebra, calculus, formal theorem proving, matrices, arbitrary scientific computation, and other advanced mathematics are not advertised as reliable capabilities without later repository evidence and evaluation results.
