# Design system

The site uses a dark-first token system in `assets/css/site.css`: black background, near-black surfaces, white primary text, gray supporting text, and lime `#76b900` for focus, primary actions, status, and small highlights. System fonts avoid third-party requests. Content is constrained to 1200px; long-form reading content is constrained to 760px.

Cards use quiet one-pixel borders and moderate 14px radii. Buttons have a minimum 46px height. Motion is limited to short interaction transitions and disabled for `prefers-reduced-motion`. All controls retain a bright, visible keyboard focus ring. The text wordmark is intentional until an approved Cinqic logo is supplied; do not invent a logo.
