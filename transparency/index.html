Pre-release information

Transparency

Clear information should accompany claims, especially for experimental AI systems.

Cinqic is preparing the technical documentation that will accompany future Juniper releases. This page will eventually contain model information, licensing details, source attribution, evaluations, limitations, privacy documentation, and release notes.

Juniper Baby 1 is currently in development. Technical documentation, licensing details, source attribution, evaluations, and model information will be published before its public release.

Current commitments

  • Publish attribution for foundation models and major dependencies.
  • Separate measured results from marketing claims.
  • Document known limitations.
  • Explain when processing is local or remote.
  • Disclose meaningful data practices.
  • Correct inaccurate public information when discovered.
  • Avoid presenting experimental systems as finished products.

Future documentation areas

Future releases may add model cards, dataset summaries, licenses, evaluation results, security disclosures, local system requirements, responsible release information, and links to source code where appropriate.
