# Cinqic landing page

The temporary coming-soon page for Juniper by Cinqic.

## Files

- `index.html` — page structure and metadata
- `styles.css` — responsive layout and motion-aware styling
- `script.js` — subtle title interaction
- `favicon.svg` — local monochrome favicon
- `CNAME` — GitHub Pages custom-domain configuration

No build process or external dependencies are required. GitHub Pages serves the site directly from the repository.
